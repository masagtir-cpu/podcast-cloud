# あなたのポッドキャスト

ニュースを自動で集めて、原稿を書き、音声にして配信する仕組みです。
**パソコンの電源が入っていなくても**、決まった曜日に新しい回が自動で作られます。

---

## はじめて設定する方へ

**[SETUP.md(導入手順)](SETUP.md) を開いて、上から順に進めてください。**

- 所要時間は30分ほど
- 費用は無料(クレジットカードの登録も不要)
- パソコンへのインストールは一切不要

> GitHubの画面は英語ですが、押す場所は手順書に全部書いてあります。

---

## 設定が終わったあと

内容はいつでも変えられます。**プログラムの知識は要りません。**

| やりたいこと | 開くファイル |
|---|---|
| 番組名・テーマ・長さを変える | `config.toml` |
| 取り上げるニュースの分野を変える | `sources.json` |
| 話し方や構成を変える | `prompts` フォルダの中の2つ |
| 配信の曜日・時刻を変える | `.github` → `workflows` → `podcast.yml` |

変更のしかたは [SETUP.md](SETUP.md) の「**番組の中身を変える**」に書いてあります。

---

## 聴き方

`Settings` → `Pages` に表示されるURLを開くと、**番組の一覧ページ**が出ます。
再生ボタンを押せばその場で聴けます。スマホのホーム画面に追加しておくと便利です。

ポッドキャストアプリに登録して自動で受け取ることもできます
([SETUP.md](SETUP.md) の手順7)。

---

## うまく動かないとき

[SETUP.md](SETUP.md) の「**困ったとき**」に、症状ごとの対処をまとめてあります。

自動実行が失敗すると、GitHubから登録アドレスに**メールが届きます**。
毎回ページを見に行く必要はありません。
