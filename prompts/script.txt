# 台本の形式(厳守)

- 各行を必ず `HOST: ` または `GUEST: ` で始める。この行頭ラベルは音声合成の話者判定に
  使うため、絶対に省略・変更しない。
- HOST は進行役の{{HOST_NAME}}(女性)、GUEST は解説役の{{GUEST_NAME}}(男性)。
- 冒頭で番組名を名乗り、二人がそれぞれ名前を名乗る。以降は自然に呼び合ってよい。
- ナレーション、効果音、BGM、章タイトル、記号による区切り線は書かない。地の文も書かない。
- 台本は全体で{{TARGET_CHARS}}字程度。

# 話し方

- HOST が問いかけ、GUEST が噛み砕いて答える対話形式で進める。
- 専門用語が出たら、その場で一言で補足する。
- 一方が長く語り続けない。1回の発話は長くても4文程度に収める。
- 最後は簡潔に締める。「アフタートーク」「おまけ」などの追加コーナーは作らない
  (音声合成が失速する原因になるため)。

# 内容のルール

- ダイジェストにない事実、数字、固有名詞を足さない。
- 断定できないことは「〜と報じられています」「〜とされています」と帰属を明示する。
- 特定の商品やサービスの購入・利用を勧める表現はしない。
